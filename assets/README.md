# 方块人物头像与来源

此目录中的五张 SVG 头像（史蒂夫、艾 Alex、苦力怕、末影人、僵尸）是为本小游戏绘制的原创方块风格示意图，不是从小红书笔记下载或复制的原图。

史蒂夫头像的构图灵感参考小红书用户「✨MC飞飞鱼🐟」的笔记《我的世界｜史蒂夫像素头像》：
https://www.xiaohongshu.com/explore/6a50966300000000060227ca

苦力怕主题参考小红书用户「巴豆」的笔记《可可爱爱苦力怕》：
https://www.xiaohongshu.com/explore/69fbff750000000036000bef

网页中的来源链接会打开对应小红书笔记。若要在网页中直接展示创作者原图，应先取得作者许可。


四张方块场景 SVG（草原、森林、矿洞、末地）也是为本小游戏原创绘制的本地像素场景插画，用作对应训练关和最终 Boss 的背景，没有使用外部图片。
